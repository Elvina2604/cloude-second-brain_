# Тестирование сервиса выборок (clients-filtering)

## Где знания
- `brain/areas/selections.md` — устройство, расчёт, ответы аналитика, риски.
- `brain/areas/selections-stands.md` — что найдено на стендах, Д-1…Д-19.
- `brain/areas/selections-api.md` — 27 публичных методов.
- `brain/areas/selections-contacts.md` — ЕКЛ.
- `brain/references/selections-test-map.md` — полная карта (живой документ: https://claude.ai/artifact/51oWHufZQ4gL53bygGM3f3).
Сначала `python brain/brain.py pack "<задача>"`, проверки — через `checks`, `defects`, `api`.

## Область (ответ аналитика 29.10)
- Входит: весь сервис, выборки клиентов, аккаунтов, контактных лиц (ЕКЛ).
- Не входит: выборки для маршрутов помощи, рассылок и кандидатов (проверки 6.1, 6.2, 1.10, 7.2 помечены «Вне области»).
- Название: обязательно, 1–255 символов, дубли разрешены. Без фильтров сохранить нельзя.
- Остановка расчёта: найденное сохраняется, статус finish. Лимит набора — 1 000 000.

## Как проектировать проверки
- Формат строки карты: № | Проверка | Ожидаемый результат | Приоритет P1–P3 | Тип UI/API/БД/НФ.
- Нет требования → «по требованиям, уточнить» + вопрос в «Открытые вопросы», не выдумывать.
- Главный риск — неверный состав при сложной И/ИЛИ. Оракулы: тот же фильтр в реестре-источнике; сравнение UseEnhancedMerge true/false; одинаковые фильтры → одинаковый результат.
- Сквозные классы: границы дат и диапазонов, пустые значения в описании фильтра, взаимоисключающие фильтры, лимит, остановка/пересчёт, права (UI + прямой вызов API), приложение (CRM/Clients/Profile) и регион (KZ/UZ).

## API
- Публичные = «Public Service Contract» на wi.saby.ru (вход в рабочий Saby делает пользователь).
- Проверки через Postman: валидный вызов, пустые/неверные параметры, навигация (списочные — версия 4), вызов без прав.

## Дефекты
- Подозрение: «Д-N | что видно | где | ожидалось | критичность» в areas/selections-stands.md.
- Баг-репорт — по brain/templates/defect.md.
- Подтверждать пересчётом/повтором, прежде чем называть дефектом.

## Стиль
Пользователь — тестировщик: кратко, по-русски, без кода. Результаты — в карту (документ) и во второй мозг.
