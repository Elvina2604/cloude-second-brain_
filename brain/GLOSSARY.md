# Глоссарий

| Термин | Значение | Синонимы |
|---|---|---|
| Выборка | Набор условий отбора клиентов/аккаунтов/контактов и найденный по ним список | сегмент segments selection папка |
| Предикат | Источник данных, привязанный к одному или нескольким фильтрам | predicate обработчик handler |
| Опорный предикат | Самый выгодный для итерирования предикат в И-блоке: мин. (N/LIMIT)×t | опорный bearing |
| DNF | Линейная форма условия: ИЛИ из И-блоков (мегапредикатов) | ДНФ мегапредикат |
| Дофильтрация | ID опорного предиката передаются в неопорные | UseEnhancedMerge enhanced_merge |
| Prefetch | Платформенный сервис кэширования отчётов, хранит результат выборки | префетч кэш |
| DWC | Сервис распределённых асинхронных сценариев, итерирует набор | итерация набор |
| ЕКЛ | Единый контактный лист — реестр контактных лиц | контакты контактные ЧастноеЛицо |
| СПП | Сервис «Проверка партнёров» — данные о всех компаниях | spp Все компании |
| Автообновление | Выборка пересчитывается сама по расписанию | автообновляемая autoupdate |
| Статическая выборка | Состав меняется только при ручном пересчёте | статическая ручной |
| Типовые выборки | Предустановленные выборки ЕКЛ: Мужчины, Женщины, до 18, от 18 до 40, от 40 | дефолтные инсталляционные |
| Public Service Contract | Публичные методы БЛ, доступные внешним вызовам | публичные API методы |
