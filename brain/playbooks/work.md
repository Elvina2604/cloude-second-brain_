# Протокол работы

## В начале задачи
1. Сформулировать задачу одной фразой.
2. `py -3 brain/brain.py pack "<задача>"` — до 4 файлов и релевантные разделы.
3. Задача неясна — `py -3 brain/brain.py brief`.
4. План 3–5 шагов до начала работы.

## Во время работы
- Факт искать через `search`, читать точечно.
- Карту тестирования не читать целиком: `checks`, `defects`, `api`, `questions`.
- Решение — сразу в DECISIONS.md; устойчивый факт — в areas/.
- Найденный дефект — по шаблону templates/defect.md в areas/selections-stands.md.

## Автожурнал
- Хук Stop (.claude/hooks/auto_journal.py) пишет sessions/auto/ГГГГ-ММ-ДД.md: последний запрос и последний ответ, с обрезкой и маскировкой секретов.
- Это черновик: нет вызовов инструментов, текст обрезан.

## В конце задачи
1. Просмотреть sessions/auto/ за сегодня.
2. `/brain-save`: журнал sessions/ГГГГ-ММ-ДД.md, STATE.md, areas/, DECISIONS.md.
3. `py -3 brain/brain.py lint` без ошибок.
4. Синхронизировать важное с Project «For work» в claude.ai (если работа шла там).

## Что не писать
- Пароли, токены, логины тестовых пользователей, персональные данные.
- Историю чата и рассуждения.
- Предположения без пометки «не подтверждено».

## Лимиты
STATE ≤ 60 строк, сессия ≤ 80, область ≤ 300, pack ≤ 7000 символов.
