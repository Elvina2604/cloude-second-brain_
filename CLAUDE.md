# CLAUDE.md — второй мозг

Пользователь — инженер-тестировщик (не программист). Отвечать кратко, по-русски, без кода, если код не просили.

## Второй мозг — обязательный протокол

Перед нетривиальной задачей (анализ, тест-дизайн, разбор дефекта, исследование стенда, правки > 1 файла):

1. `python brain/brain.py pack "<задача>"` — минимальный контекст (на Windows можно `py -3`).
2. Задача не сформулирована — `python brain/brain.py brief`.
3. Открывать только файлы и разделы из выдачи `pack`/`search`. Не сканировать весь репозиторий.
4. После работы — `/brain-save`: brain/sessions/ГГГГ-ММ-ДД.md, brain/STATE.md, areas/, DECISIONS.md.
5. `python brain/brain.py lint` без ошибок.

`brain/sessions/auto/` — автожурнал хука Stop, только черновик.

## Правила
- Пароли, токены, логины тестовых пользователей не записывать в brain и не выводить.
- Не выдумывать требования: неподтверждённое — «не подтверждено» или открытый вопрос.
- Рабочие записи — по-русски, коротко, с датами и ссылками на файлы.
